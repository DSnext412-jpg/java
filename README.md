## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DSnext412-jpg/java.git
```

### 2. Open the project folder

```bash
cd java
```

### 3. Check your Java installation

```bash
java -version
javac -version
```

Install a JDK if these commands are unavailable.

### 4. Compile a program

For example, to compile `sum.java`:

```bash
javac sum.java
```

### 5. Run the program

Use the class name declared inside the Java file:

```bash
java ClassName
```

> **Note:** The Java class name may differ from its filename. Check the source file and use the class containing the `main()` method. Compile and run each standalone program separately.
